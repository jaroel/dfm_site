# Dinxper FM site

Solid 2 app in start mode (`@solidjs/vite-plugin`), streaming SSR, bun server.

## Developing

```bash
bun install
bun run dev
```

## Building

```bash
bun run build   # dist/client + dist/server
bun run start   # bun server.bun.ts
bun run preview # vite preview
```

## Testing

```bash
bun run test
```
