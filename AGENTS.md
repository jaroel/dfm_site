# AGENTS.md

Agent-facing map for this repo. Human quickstart lives in `README.md`.

## Stack

- Solid 2 (`solid-js`, `@solidjs/web`, `@solidjs/router`, `@solidjs/meta`)
- Start mode via `@solidjs/vite-plugin` + `filesystem-routing`
- Vite 8, Tailwind 4, Vitest, Bun 1.4+
- Bun only. Do not use npm or pnpm.

Before changing Solid code, load the Solid skills in `node_modules/solid-js/skills/`
when present: `solid-2.0`, `solid-2.0-cheatsheet`, `reactivity-diagnostics`.

## Commands

```bash
bun run dev        # Vite dev server, run through Bun on purpose
bun run build      # dist/client + dist/server/server.js
bun run start      # bun server.bun.ts (needs dist + node_modules)
bun run preview    # Vite preview of the build
bun run test       # vitest
bun run lint       # oxlint
bun run typecheck  # bun check for server + tsconfig.client.json
```

`dev` calls `bun node_modules/vite/bin/vite.js` deliberately; the Bun runtime is required.

## Routes

| URL | File |
|---|---|
| `/` | `src/routes/(home).tsx` |
| `/uzg/` | `src/routes/uzg/(uzg).tsx` |
| `/uzg/:file_name` | `src/routes/uzg/[file_name].ts` (GET audio stream, 206 range) |
| `/*404` | `src/routes/[...404].tsx` |

`file-routes.d.ts` is generated by `fileRoutes({ types: true })` in `vite.config.ts`.
Do not edit it by hand.

## Data flow

```text
src/ftp.ts        FTP listing + stream, server-only
  -> src/uzg.ts   fetchUzgListing ("use server"), toRecordings
  -> src/routes/uzg/(uzg).tsx  query(fetchUzgListing)
  -> Player.tsx + Controls.tsx
```

`src/middleware.ts` wires the `filesystem-routing` API handler. `src/uzg.ts`
(server data/formatting) is not the same layer as `src/routes/uzg/` (pages/API).

## Build and runtime

- `bun run build` emits `dist/client` and `dist/server/server.js`.
- `bun run start` runs `server.bun.ts`, which imports `dist/server/server.js`.
- Docker runs `bun build server.bun.ts` and ships `server.bundle.js` + `dist`.
  The runtime image has no `node_modules`.

## Images

`@responsive-image/solid` + `@responsive-image/vite-plugin`.

- `?responsive` + `?w=...&format=avif;webp;png&lqip=...` produces responsive sources.
- `?url` returns a plain asset URL.
- `responsiveImage()` in `vite.config.ts` processes both forms.
- Types come from `@responsive-image/vite-plugin/client` (see `tsconfig.json`).

## Gotchas

- FTP credentials are hardcoded in `src/ftp.ts`. The container gets no env.
  `FTP_*` variables in `.env` are not read.
- `isServer` comes from `@solidjs/web` in Solid 2, not `solid-js`.
- Do not debug behavior from hashed bundles in `dist/`; use `dev` or `preview`.
- Package versions are prerelease/RC. `package.json` and `bun.lock` are the
  source of truth when docs or templates disagree.
